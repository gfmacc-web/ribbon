# Ribbon Safe Site

Site estático completo para venda do produto Ribbon Safe.

## Arquivos principais

- `index.html`: site completo de venda.
- `assets/`: imagens promocionais usadas no site.
- `docs/PASSO_A_PASSO_GITHUB.md`: passo a passo para publicar no GitHub Pages.
- `docs/ESPECIFICACOES_PRODUTO.md`: especificações comerciais do produto.

## Como abrir localmente

Clique duas vezes em `index.html` ou abra o arquivo no navegador.

## Como publicar

Siga o arquivo `docs/PASSO_A_PASSO_GITHUB.md`.

## Observação

O botão de compra abre um WhatsApp fictício. Troque o número `5511987654321` pelo número real do grupo ou vendedor.
